# FantasyEliminator

## Description
This is a season long twist on fantasy football. Instead of drafting a team at the beginning of the season, you select one player each week to score points for your team. You can only select a player once per season, and each position must be selected 4 times per season(except for kicker and defense). The deadline for selecting players is generally sunday at 9am. If you select a player that is playing on a Thursday or Saturday, those picks must be in before that game kicks off. At the end of the season, the team with the most points wins.

This app is a work in progress and is not currently deployed. 
It is built on a MERN stack, with Material UI for styling elements.
## Instructions 
To get started, clone the repository and run `npm install` in the root directory. Then run `npm run develop` to start the development server. This is how you can get the app running locally and how I will be testing it for the purpose of this project.
